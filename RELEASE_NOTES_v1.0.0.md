# Outfitter 5.21 Legion 7.3.5 — v1.0.0

A compatibility release of **Outfitter 5.21** for **World of Warcraft Legion 7.3.5 / Interface 70300**.

Original Outfitter is by **John Stephen / Mundocani**. This release preserves the original author credits and MIT license. Compatibility modifications are by **JustAlex888**.

## Highlights

- Legion 7.3.5 compatibility fixes for the official Outfitter 5.21 line.
- Fixed the confirmed title-menu Lua crash caused by a nil title name.
- Specialization-based visibility filtering for Outfit Bar icons without auto-equipping.
- Dedicated two-trinket **Accessories** sets.
- Independent movable **Accessory Bar** with its own size, opacity, orientation, lock and background settings.
- Repeat-click on an active Accessories set restores the base outfit's trinkets.
- Improved Russian localization and explicit RU/EN UI switching for testing/screenshots.
- Separate patch-author page while preserving the original animated Outfitter credits page.

## Compatibility

- Target: WoW Legion 7.3.5
- Interface: 70300
- Upstream: Outfitter 5.21
- SavedVariables preserved

## Install

Replace only `Interface/AddOns/Outfitter`. Do not delete WTF/SavedVariables by default.

See `INSTALL.md` for details.

## Release asset

Use the prepared install ZIP, not GitHub's automatically generated `Source code.zip`, as the user installation package.
