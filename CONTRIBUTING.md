# Contributing

Bug reports and narrowly scoped Legion 7.3.5 compatibility fixes are welcome.

When reporting a problem, include where possible:

- WoW client/version and Interface number;
- exact Outfitter release/build;
- reproduction steps;
- relevant BugGrabber/Lua error;
- whether the issue also occurs with upstream behavior;
- screenshots only when they help explain UI behavior.

Please keep changes compatible with existing SavedVariables and avoid unrelated modernization of the legacy addon.
