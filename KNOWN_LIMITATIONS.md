# Known limitations

- Target client is **WoW Legion 7.3.5 / Interface 70300** only.
- Compatibility with modern Retail, Classic branches, BfA clients, or unrelated private-server API variants is not claimed.
- `/outfitter lang en|ru` changes Outfitter-owned UI strings only. Item names, player-created outfit names, player titles and other game-provided text continue to follow the actual WoW client locale.
- Legacy partial outfits remain preserved in SavedVariables for compatibility but are hidden from the normal primary category view in this branch.
- The new Accessories feature is intentionally limited to the two trinket slots. It is separate from legacy partial outfits.
- Not every historical Outfitter automation script has been exhaustively tested on every class/spec/zone in Legion 7.3.5.
